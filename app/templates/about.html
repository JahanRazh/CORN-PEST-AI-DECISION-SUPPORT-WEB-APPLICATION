Research method

How this system decides

{{ APP_NAME }} is a context-aware decision support system that pairs a deep-learning pest classifier with an expert rule base. It is built around a deliberate separation of responsibilities: each layer answers exactly one question, and every answer is shown to the user rather than hidden behind a single label. This page documents what each layer does, the thresholds it uses and the literature those thresholds come from.

Rejecting what the model does not know

Rejection happens in two stages. A relevance gate first asks whether the photograph is even of an insect or a plant, using an ImageNet-pretrained MobileNetV2 — no additional training data is needed, which is why the gate could be deployed before any OOD dataset was collected. Images that clear the gate are then scored by four distributional signals derived from the pest classifier's own output.

Voting, not vetoing

At least {{ ood_config.votes_required }} signals must flag an image before it is rejected. Any single signal can misfire on a legitimate but unusual photograph; requiring agreement trades a little sensitivity for far fewer false rejections. The one exception is the relevance gate's hard reject at a score below {{ ood_config.get('relevance_hard_reject', 0.010) }}, which fires alone because an image containing no insect or plant at all cannot be a corn pest.

Where the recommendations come from

No recommendation text is generated. Every active ingredient, trade name, pre-harvest interval, IRAC group and biological agent is read from the project's Excel workbook, and every result page names the record it came from. The rule engine's contribution is ordering and filtering: it decides which of the available options fit the reported growth stage, severity, weather and harvest window, and it records the rule behind each decision.
